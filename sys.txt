################################################################
PART A — YE EDITOR KYA HAI?
################################################################

Noni = terminal (TUI) code editor, ncursesw pe.
Inspired by vim modes + VS Code-style workbench actions (Ctrl / Space chords).

Ek line mein:
  Files kholo → vim-style edit karo → LSP se smart help → git gutter →
  integrated terminal → session yaad rakhe → tree-sitter se colors.

Entry: noni.cpp::main → Logger::init → Args::get_file_path(argv[1]) → UI(file_path)::run → Logger::shutdown.

Target user: keyboard-first, local projects, C++/Python/etc. with LSP.

Code me debugger / SSH / GUI / plugin marketplace UI nahi hai.

T2) KeybindingEngine chord parsing + when-flags
-------------------------------------------------------------------

parse_key / parse_single (keybindings_part2.cpp + keybindings_detail.hpp)
  Chord = whitespace-separated tokens. Example "ctrl+k s" → [ctrl+k, s].
  Each token: zero or more mod+ prefixes then key name. Spec lowercased.
  Unknown names leave code==0 (binding dropped if chord empty).

Modifiers:
  ctrl / control / c  → ctrl
  alt / option / a    → alt
  shift / s           → shift

Named keys → stored code:
  escape/esc=27  tab='\t'  enter/return='\n'  space=' '  backspace/bs=127
  up/down/left/right  pageup/pgup  pagedown/pgdn  home/end  delete/del  insert/ins
  f1…f12 = KEY_F(1)…KEY_F(12)
  slash=/  period/dot=.  comma=,  semicolon=;  colon=:
  quote/doublequote="  apostrophe/squote='  question=?  bang/exclaim=!
  ` / backtick / grave
  \ / backslash
  [ / leftbracket   ] / rightbracket
  - / minus   = / equals / plus   _ / underscore
  single ASCII letter; shift+x → 'X' and shift=true; uppercase also sets shift

Leader: first token is leader iff !ctrl && !alt && code==' ' (is_leader_token). Flag ResolvedBinding.leader.

from_raw (keybindings_raw.cpp) — get_wch → KeyToken. First: keybindings_ext::apply_extended
  (define_key CSI 1;3 Alt / 1;5 Ctrl / 1;7 Ctrl+Alt arrows+home/end/pg/del/ins).

raw | token
27 | Esc code=27
'\t' | Tab
